# 微博舆情监测 AI 辅助分析系统

> 一个用 **Selenium + 本地大模型**把「微博热搜抓取 → 舆情研判 → 邮件推送」串成自动流水线的舆情监测工具，面向**舆情分析 / 国际传播**场景；凭据本地保存、不上传。

## 📌 项目简介

做微博舆情监测，最重复的不是分析，而是**反复登录、搬榜、摘推文**。这个工具把「扫码登录 → 抓取热搜与前 N 页高热度推文 → 本地大模型研判 → 关键词长期监控自动邮件推送」全部自动化，且**模型完全本地部署（Ollama）**，不依赖任何外部 API、不泄露账号信息。

## ✨ 核心亮点

- **扫码登录 + Cookie 持久化**：用 Selenium 扫码登录微博，Cookie 落地本地复用，免去重复登录。
- **热搜榜可视化抓取**：读取微博热搜榜并呈现，可选中任意热搜抓取其前 N 页高热度推文（页数可配置）。
- **本地大模型研判**：抓取内容交本地部署的大模型，产出舆情的**起因 / 经过 / 结果 / 未来趋势**研判，可切换不同本地模型。
- **关键词长期监控**：设定间隔轮询热搜榜，命中关键词后**自动抓取 → 自动分析 → 自动邮件推送**，网页关闭也能后台持续运行。
- **零外部依赖的分析链路**：研判走本地 Ollama，邮箱配置本地保存，整套流程不触外部服务。

## 🚀 快速开始

```bash
# 1. 安装依赖
pip install selenium requests

# 2. 运行（首次会弹出扫码登录）
python 微博舆情监测ai辅助分析系统.py
```

- 监控任务：在界面设定关键词与轮询间隔，命中后自动抓取分析并邮件推送。
- 邮件推送需在本地配置 SMTP 账号（仅存于本机，不进仓库）。

## 🔒 隐私与安全

- 微博 Cookie、SMTP 邮箱账号等凭据**仅保存在你本机**，仓库内不含任何密钥或个人信息。
- 舆情分析走本地大模型，推文数据不外传。
