# 微博舆情监测 AI 辅助分析系统

> 分类：舆情工具
>
> Python + Selenium 实现微博扫码登录、热搜与前 N 页推文抓取，交由本地大模型产出舆情研判，支持关键词长期监控与邮件推送。
>
